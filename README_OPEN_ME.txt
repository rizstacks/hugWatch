HOW TO OPEN
1. Unzip this folder.
2. Open Godot 4.x.
3. Click Import.
4. Select project.godot inside this folder.
5. Press Play/F5.

CONTROLS
WASD = move
Mouse = look
Shift = sprint
Space = jump
E = interact
Esc = release/capture mouse

WHAT IS INCLUDED
- A fully generated closed school-like level/box
- Hallway + classrooms + floor/walls/ceiling
- First-person player controller
- Doors that open/close
- Lockers, desks, radio, whiteboard interactions
- HUD: crosshair, objective, interaction prompt, messages
- Your uploaded school FBX and textures in res://assets/

NOTE
The game does not depend on the FBX importing correctly. It runs using Godot-built meshes first, so it should open cleanly.
